# poodi-ai

Working repository for a social map app. The repository name is a working name.

| Folder | What it holds |
|---|---|
| `landmarks/` | 3D models of famous structures, written as code. Start with `landmarks/BRIEF.md`. |

More folders arrive as the app is built.

## Rules

- Changes arrive through pull requests. Nothing is pushed straight to `main`.
- A pull request for a landmark model touches only `landmarks/`.
- No secrets, keys or tokens in the repository.
